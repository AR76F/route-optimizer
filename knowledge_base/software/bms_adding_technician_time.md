# BMS - Adding Technician Time

# Last Updated: 2026-08-31

## Purpose

This procedure explains how to **manually add technician labor time to a Work Order in BMS** using the Post Time Inout function.

It is intended for situations where technician time must be entered manually and associated with the appropriate Work Order.

## Objectif

Cette procédure explique comment **ajouter manuellement du temps de technicien à un bon de travail dans BMS** à l'aide de la fonction Post Time Inout.

Elle s'applique aux situations où les heures d'un technicien doivent être saisies manuellement et associées au bon de travail approprié.

---

## Quick Reference / Référence rapide

The general process consists of:

1. Open **Post Time IN/OUT** in BMS.
2. Enter the appropriate location, such as **Z8** for Candiac.
3. Select the applicable **Pay Period**.
4. Search for and select the technician.
5. Select the applicable work date.
6. Enter the technician's start and end times. The total hours are calculated automatically.
7. Enter the appropriate **Pay ID** and **Pay Type**. For regular time, use `RT`.
8. Under the Work Order information, enter `WO` as the transaction type.
9. Enter the applicable Work Order number under **Order Ref#**.
10. Review the information and save using **F10** or the Save button.

The official visual procedure should be consulted for the exact BMS screens, field locations, and navigation sequence.
