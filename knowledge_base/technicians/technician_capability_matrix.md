## Purpose

This document is a quick dispatch reference for selecting Power Generation technicians.

It summarizes training coverage, security certifications, and work preferences in a compact matrix format so the assistant can retrieve the most relevant technician candidates quickly.

> **Note**
>
> This matrix is intended to support technician selection, not replace the detailed technician profile files.

## How to Use

Use this matrix to shortlist technicians by:

- experience
- assignment status
- security clearance
- route / overtime preferences
- engine, project, and PM preference

Then consult the detailed technician profile for the final recommendation.
