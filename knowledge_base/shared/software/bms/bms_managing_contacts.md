# BMS Customer Contacts - Quick Reference

## Remove a Customer Contact

Use this when a customer advises that an existing contact is no longer employed by their organization.

1. Open the customer in **BMS**.
2. Locate the applicable contact.
3. Select the contact.
4. Use **Ctrl + F6** to remove the contact.

> **Note:** This instruction is based on branch operational knowledge and should be confirmed if the BMS behavior differs.
