# Employee Nameplate Template

# Version 1.0.0

# Last Updated: 2026-08-28

# Updated By: Jipeng Li

# Change Log:

v1.0.0
- Creation of initial document.

## Purpose

This resource provides the official template used to create and print employee nameplates.

The template includes:

- Standard employee nameplate format.
- R.C.R. identification format.
- Employee name customization.
- Formatting intended for color printing.

---

Cette ressource fournit le modèle officiel utilisé pour créer et imprimer les plaques nominatives des employés.

Le modèle comprend :

- Le format standard de plaque nominative pour les employés.
- Le format d'identification R.C.R.
- La personnalisation avec le nom de l'employé.
- La mise en page prévue pour l'impression en couleur.
