# Generator Warranty Overview

## Purpose

This document describes the Onan generator-warranty path when the failed component belongs to the generator assembly rather than the engine. Use it together with the shared warranty procedures.

## When This Path Applies

Use the Onan generator warranty path when:

- The failed component belongs to the Onan generator assembly.
- The technician's diagnosis identifies a generator-related failure.
- PGBU confirms applicable Onan warranty coverage.

If the failed component belongs to the engine, follow the CECO generator-engine warranty procedure. If the repair is covered through a distributor warranty arrangement, follow the distributor warranty procedure.

## Required Information

Before creating the claim, confirm:

- Generator serial number
- Date in Service
- Failure date
- Current operating hours
- Failed component and root cause
- Technician diagnosis and repair actions
- Repair location: in-shop or field service
- Applicable Onan coverage

## Coverage Verification in PGBU

1. Open PGBU.
2. Go to **Tools & Resources → Warranty Coverage Lookup**.
3. Enter the generator serial number and **Fail Date**.
4. Confirm that **Date in Service** populates automatically.
5. If it does not populate, the generator may not be registered. Follow the applicable registration process before relying on the coverage result.

Use **Fail Code Inclusion List** in the same workflow to identify the permitted Failure Code for the failed component.

## Résumé en français

Utiliser la garantie Onan lorsque la pièce défectueuse appartient à la génératrice plutôt qu’au moteur. Vérifier la couverture dans PGBU avec le numéro de série et la date de défaillance.
