# Electric Bus Warranty Overview

## Purpose

This document describes the CECO warranty path for Cummins electric-bus systems. Use it together with the shared warranty procedures and the electric-bus claim details in [Electric Bus Warranty Claims](electric_bus_claims.md).

## Electric-Bus Systems

The presentation identifies these electric-bus system groups:

- **30 — Battery Electric System:** motor harness, ECM, drive selector, high-voltage enclosure, and ECM calibration
- **31 — Energy Storage:** high-voltage battery pack, high-voltage battery control junction box, and mounting brackets
- **32 — Power Distribution:** high-voltage DC junction box and high-voltage/low-voltage wiring harnesses
- **33 — Power Electronics:** DC/AC inverter, air compressor, charge control unit, power steering, AC battery charger, and brake converter
- **34 — Propulsion System:** propulsion system control module, propulsion motor, and propulsion inverter
- **35 — Thermal Management System:** coolant filter, cooling system, and thermal management system

The exact component and model must be confirmed before selecting the Failure Code.

## Product Identification

Electric-bus models use an `EV___B` model designation. The presentation lists multiple BES ECM configurations, including CM2450, CM0904, CM0196, and related model variants. Confirm the exact model and ESN in QuickServe Online before creating the claim.

## Coverage Evaluation

Before beginning a claim, confirm:

- Date in Service
- Unit mileage
- Failed component
- Root cause
- Progressive damage, if applicable
- Unit correctly entered in the Work Order
- Applicable CECO coverage

Use Guidanz, QuickServe Online, or the approved warranty assistant and documentation to verify coverage. If the Date in Service cannot be found, contact the customer or the appropriate vehicle/OEM resource identified in the training material.

## Failure-Code Reference

Use QuickServe Online document `5579915`, **Warranty Failure Code Manual for All Electrifications**, to identify the exact component and Failure Code for the electric-bus model.
