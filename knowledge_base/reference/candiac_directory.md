# Directory Maintenance

## Adding a Person

Add the employee as a new row under the appropriate section.

Use the following format:

```text
| Full Name | Mobile Number | WWID | Extension |
```

Use:

```text
—
```

when a value is not available.

---

## Updating a Person

When an employee's:

- Mobile number changes
- WWID changes
- Extension changes
- Function changes
- Branch changes

update the existing row.

If the employee changes function or location, move the row to the appropriate section.

---

## Removing a Person

When an employee leaves the department:

1. Remove their row from the active directory.
2. Update the document version.
3. Update the Last Updated date.
4. Record the change in the Change Log.

Do not retain former employees in the active directory unless there is a specific operational reason to do so.

---

## Updating Operational Contacts

Operational and branch numbers should be reviewed whenever the source telephone directory is updated.

Pay particular attention to:

- Service Urgence
- Pièces Urgence
- Ottawa On Call
- Work Alone
- Branch telephone numbers

These numbers may affect active service operations and should remain current.
